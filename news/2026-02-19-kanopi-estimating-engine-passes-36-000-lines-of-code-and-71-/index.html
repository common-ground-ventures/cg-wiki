Kanopi Estimating Engine Passes 36,000 Lines of Code and 71 Skill Definitions

News · February 19, 2026

Posted September 2026. Covers February 19, 2026.

Posted September 2026 · covers February 19, 2026

PHOENIX, AZ, February 19, 2026. Kanopi, the construction estimating platform Common Ground was engaged to build in January, has reached its first architecture milestone: roughly 36,000 lines of code across the product family, anchored by a 16,209-line Python estimating engine spanning 32 modules, and 71 skill definitions covering the full plan-to-bid production lane.

The engine's modules run plan parsing, pricing, ratio checks, bid assembly, verification gates, and branded PDF output. The differentiating layer is verification: every takeoff is subjected to a mandatory blind adversarial second pass, an independent re-derivation of quantities with no visibility into the first pass. In one internal validation, that process caught a 32 percent shell-height error before the estimate left the building.

Accuracy in estimating is not a single percentage. It is a discipline. Kanopi's position is that the second set of eyes should be structural, not optional.
