Wiki/Stories/A vote is an opinion; a review is an analysis

In July 2026 an FDA advisory committee recommended six peptides for the 503A bulks list.

We moved the legal-access axis and left the science and safety grades alone.

No trial had read out, so the evidence hadn't changed. The FDA's own scientific review found the human safety data insufficient. A vote is an opinion. A review is an analysis.

Access moved. The grades did not.

Ten weeks later there was still no FDA rule. A grade bumped on the vote would have been sitting there, waiting to be walked back.

Keep separate axes for separate questions, so a headline can't quietly move a grade.
