Wiki/Stories/Nothing ships on one pass

I sell estimates and takeoffs for a living now, and the number on that document is the whole product. So nothing ships without a blind second pass, no exceptions. Not for a simple job, not for a client in a hurry. A separate pass, done by someone or something that never saw the first measurement, remeasures the plans from scratch, and the two versions have to reconcile before anything goes out the door. I did not set this rule because I like process for its own sake. I set it because the pass keeps finding real errors the first one misses. A wrong window count. A plate height read wrong off the page. A shell dimension off by a third. One manufacturer ran three blind same day takeoffs against my numbers and came back saying it was close enough that they wanted to buy the system outright. We are liable for every number we send, and the cost of one wrong bid dwarfs the cost of a second independent look, every single time.
