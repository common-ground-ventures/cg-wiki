In July 2026 a posting asked for someone to automate investor materials: keep the decks current from the numbers without breaking the approved design. A posting like that draws many pitches describing how the work would be done.

Robby Prochnow built it instead, in about a day. The engine keeps every figure in one data layer and refreshes an approved deck in place, rewriting only the text and never the layout. He wired 46 fields to source, added a sign-off step for a subject-matter expert, and produced versions for pension, endowment and family-office audiences on demand. A machine-checked manifest showed zero shapes added or removed, so the deck compliance approved is the deck that ships.

The demonstration ran on fictional data. The pitch line was simple: the client had seen a great many descriptions of how someone would build this, and here was one that was built.
