An independent financial advisory practice: second in organic search in week one

Work · Technology

A publishing system and a local landing page for an independent financial advisory practice ranked second in organic search for a competitive metro retirement-planning keyword within the first week, with no ad spend.

Wiki/Work/Search build for an independent financial advisory practice

What it is

An independent financial advisory practice wanted to be found by people searching for retirement planning in its metro area, a crowded and competitive search, and needed a way to publish steadily in a field where what gets published is sensitive.

The decision

Zen Aegis built the practice an owned publishing system and a local landing page and put no money into ads.

What Zen Aegis did

  • Built custom page templates for the practice's site.
  • Set up a blog source of truth so every post comes from one place.
  • Wrote a 90-day editorial calendar.
  • Built a local search landing page.

Results

  • Ranked second in organic search for a competitive metro retirement-planning keyword within the first week of publishing.
  • $0 in ad spend.
