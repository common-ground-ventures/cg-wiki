Cascade IR: an investor-materials engine built within a day of the posting

Work · Technology

Within about a day of a posting for investor-deck automation, Zen Aegis built a working engine that refreshes approved investor decks in place from one data layer, with 46 fields wired to source and no change to the design.

Wiki/Work/Cascade IR

What it is

Investor relations teams rebuild the same decks every quarter, and every rebuild risks a number that drifts from the source or a slide that no longer matches the approved design.

The decision

Instead of describing how it would build the engine, Zen Aegis built a working proof of concept and showed it.

The engine changes only the text in an approved deck, never its layout, so the deck that compliance approved is the deck that ships.

What was built

  • Built one canonical data layer for the figures.
  • Built a refresh that rewrites only the text runs in approved decks.
  • Wired 46 fields to source and added a sign-off gate for a subject-matter expert.
  • Built instant variants for pension, endowment and family-office audiences.
  • Ran the demonstration on fictional data.

Results

  • A working engine in about 24 hours, between July 8 and 12, 2026.
  • 46 fields wired to source, with a machine-checked manifest showing zero shapes added or removed.
