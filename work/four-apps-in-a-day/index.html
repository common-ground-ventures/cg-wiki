Four working apps built live in one day, and an agent that tested its own tools

Work · Technology

Zen Aegis built four working apps live in a single day as a public demonstration, including a commercial insurance quoting tool and a credit intelligence tool, and separately had an autonomous agent build and compare two rapid-development platforms.

Wiki/Work/Four apps in one day

What it is

Anyone can say they build fast. A live build puts the claim where people can watch it and check it afterward.

The decision

Zen Aegis built in public, live, with the repositories left open so the work and its dates can be checked.

For the platform comparison, the evaluation was handed to an autonomous agent, which built the same test on each platform and compared them itself, rather than a person.

What was built

  • Built a credit intelligence tool.
  • Built a commercial insurance quoting intelligence tool.
  • Built the challenge site and exported the automation workflows behind it.
  • Had an autonomous agent build and compare two rapid-development platforms.

Results

  • Four working apps in one day, with public repositories created April 10, 2026.
  • The agent-run platform comparison is public, with repositories created March 18, 2026.
