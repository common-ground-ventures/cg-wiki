Filing a fire code appeal instead of altering a 1971 structure

Wiki/Stories/Filing a fire code appeal instead of altering a 1971 structure

The 1971 building's underground parking garage runs past the distance fire code allows for truck access, and the structural columns on the parking deck don't leave room for the turning radius the trucks need. The straightforward fix would've meant altering structural columns on a concrete structure that's fifty five years old.

Instead of redesigning the garage or the access, we filed a technical code appeal arguing the required access distance should be extended, on the grounds that changing the structure itself wasn't feasible.

The appeal leaned on three things holding at once: the building already has a sprinkler system being modernized, real fire protection is reachable from two adjacent streets, and this isn't the kind of high occupancy use that needs the tighter standard. Changing structural members on a building that old, just to fix an access distance, I judged not feasible. So the appeal asked the code to bend around what's actually true on the ground instead.

We filed that appeal in December 2025. Then it sat unread internally for months, until an audit rediscovered it had already been filed, and corrected the stale assumption that it was still waiting on a signature. A decision from the Fire Marshal is still pending as of the most recent files I've seen.

Sometimes the right fix for an old building isn't to change the building. It's to make the case for why the rule should flex around what's actually true about it.

An appeal that had already been filed sat mislabeled as still pending for months. That's a paperwork tracking gap, not anyone's real failure, and it got caught and corrected instead of left to compound.
